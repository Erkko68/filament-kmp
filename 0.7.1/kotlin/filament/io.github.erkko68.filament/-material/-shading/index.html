Shading

enum Shading : Enum<Material.Shading>

Shading model determines how light interacts with the material surface.

  • UNLIT: No lighting applied; emissive possible. Useful for UI, billboards, glow effects

  • LIT: Standard physically-based lighting (default)

  • SUBSURFACE: Subsurface scattering for thin materials (skin, leaves, paper)

  • CLOTH: Cloth-specific lighting model for fabric appearance

  • SPECULAR_GLOSSINESS: Legacy shading model (use LIT for new materials)

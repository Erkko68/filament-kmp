TangentSpaceMesh

class TangentSpaceMesh(nativeHandle: NativePointer) : AutoCloseable

Builds Filament-style TANGENTS buffers (tangent-space quaternions) from an input mesh, with a choice of algorithms. Supersedes SurfaceOrientation.

If the chosen algorithm didn't remesh the input (remeshed), use the data you provided instead of querying it back. Getting positions or UVs that weren't provided as input aborts.

TransferFunction

data class TransferFunction(val a: Double, val b: Double, val c: Double, val d: Double, val e: Double, val f: Double, val g: Double)

An ICC parametric curve type 4 (ICC.1:2004-10, 10.15): the EOTF is Y = cX + f for X < d and Y = (aX + b)^g + e otherwise; the OETF is its inverse. The 5-parameter constructor (e = f = 0) is curve type 3.

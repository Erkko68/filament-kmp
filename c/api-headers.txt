# The Filament headers the Fila* C API is generated from (generateCApi), and that apiModel/apiGaps report on.
# Globs relative to include/, grouped by the C module (c/<module>) their declarations are generated into.
#
# Every public class and free function these headers declare gets C functions. Types they use from other
# headers (backend/, math/, utils/) are bridged as C types only, into the first module. `!glob` excludes headers
# (the generator fails on listed headers it finds no declarations in).
#
# `-regex` leaves out the C++ declarations whose qualified name it matches: a record (with everything nested), a member,
# or a function; one overload as `-Record::method\(Type, …\)`. `-Record::.*` keeps the record's handle but none of its
# members. Methods and fields whose types use a skipped record go too. The generated headers note each skipped member;
# an entry matching nothing fails the generator.
#
# An enum, enum value or constant has no C function: its entry only tells apiCoverage that Kotlin leaves it undeclared
# on purpose.

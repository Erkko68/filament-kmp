fun async(callback: (IndexBuffer, AsyncCallStatus) -> Unit = { _, _ -> }): IndexBuffer.Builder

Creates the IndexBuffer asynchronously: callback runs once on the main thread when its memory is allocated (AsyncCallStatus.CANCELED if it never was). Until then, only async calls on it are safe; check IndexBuffer.isCreationComplete. Needs Engine.isAsynchronousModeEnabled.
